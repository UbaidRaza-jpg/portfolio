## Overview

A fast, accessible engineering portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript. Designed for technical recruiters to review qualifications, projects, academic background, and contact options directly.

- Light theme: off-white canvas (#FAFAF9), dark text (#09090B), electric indigo accent (#4F46E5)
- Shared 1280px container layout with alternating section backgrounds
- Contained bust portrait composition with CSS running text marquee and bottom fade mask
- Two-column hybrid contact interface supporting direct communication channels and asynchronous message dispatch via FormSubmit
- Zero frameworks and zero build steps
- Fully responsive across viewports from 390px to 1920px
