## About This Portfolio

A **UEFA Champions League + Real Madrid** broadcast-themed personal portfolio built entirely with vanilla **HTML, CSS, and JavaScript** — no frameworks, no libraries, just pure craft.

The concept mirrors a live football broadcast matchday experience:
- **Pre-match lineup reveal** — projects pop onto a 3D tactical pitch one by one
- **3D FUT/EA Sports style player card** — with real photo, stats, and holographic tilt effect
- **VAR Match Report modals** — clicking a project opens a deep-dive technical analysis
- **Synthesized Web Audio engine** — referee whistle, stadium crowd ambiance (zero MP3 files)
- **Live Broadcast HUD** — sticky matchday ticker with transfer status
